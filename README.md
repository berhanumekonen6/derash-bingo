# 🎰 ደራሽ ቢንጎ (Derash Bingo)

A complete BINGO game platform integrated with Supabase backend, built with Streamlit.

## 📋 Features

- ✅ User Registration & Authentication
- ✅ Card Selection (1-2 cards per player)
- ✅ Automatic Number Calling
- ✅ Winner Detection & Celebration
- ✅ Real-time Prize Pool
- ✅ Balance Management
- ✅ Admin Dashboard

## 🎯 Game Rules

| Rule | Value |
|------|-------|
| **Card Price** | 10 ETB |
| **Prize Pool** | 8 ETB per card |
| **Max Cards** | 2 per player |
| **Selection Time** | 60 seconds |
| **Number Range** | 1-75 |
